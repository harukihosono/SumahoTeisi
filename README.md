# SumahoTeisi EA

スマホからの緊急停止機能付きEA（MT4/MT5対応）

## 概要

特定の指値注文を検出した際に自動売買を停止し、指値注文を削除するEAです。
スマホから緊急でEAを停止したい場合に、特定の指値注文を入れることでトリガーできます。

また、価格が設定した上限・下限を超えた場合に全ポジションを決済してEAを停止する機能も搭載しています。

## 機能

### 1. スマホ緊急停止機能
以下の条件の指値注文を検出すると、自動売買をOFFにして指値注文を削除します：
- USDJPY: 売り指値 @ 200.0
- BTCUSD: 売り指値 @ 200000.0

該当注文がなくなると、自動売買を元の状態に復元します。

### 2. 価格制限による全決済・停止機能
- 価格が上限を超えた場合、または下限を下回った場合に発動
- 全ポジション決済
- 全待機注文削除
- 自動売買OFF
- EA自動削除（完全停止）

### 3. 通知機能
価格制限トリガー時に以下の通知を送信可能：
- ポップアップアラート
- スマホプッシュ通知
- メール通知

## パラメータ

| パラメータ | デフォルト | 説明 |
|-----------|----------|------|
| 上限価格（0=無効） | 0.0 | この価格を超えたら全決済して停止 |
| 下限価格（0=無効） | 0.0 | この価格を下回ったら全決済して停止 |
| ポップアップメッセージ表示 | true | アラートを表示するか |
| スマホ通知（プッシュ通知） | false | プッシュ通知を送信するか |
| メール通知 | false | メール通知を送信するか |

## インストール方法

### MT4の場合
1. `SumahoTeisi_Common.mqh` を `MQL4/Include/` フォルダにコピー
2. `SumahoTeisi.mq4` を `MQL4/Experts/` フォルダにコピー
3. MetaTrader 4を再起動またはナビゲータを更新
4. コンパイル

### MT5の場合
1. `SumahoTeisi_Common.mqh` を `MQL5/Include/` フォルダにコピー
2. `SumahoTeisi.mq5` を `MQL5/Experts/` フォルダにコピー
3. MetaTrader 5を再起動またはナビゲータを更新
4. コンパイル

※ 同一フォルダに配置する場合は、includeパスの変更は不要です。

## 通知設定

### スマホプッシュ通知を使用する場合
1. スマホにMetaTraderアプリをインストール
2. アプリ内でMetaQuotes IDを確認
3. PC版MetaTraderの「ツール」→「オプション」→「通知」でMetaQuotes IDを入力
4. 「通知を有効にする」にチェック
5. EAパラメータで「スマホ通知」をtrueに設定

### メール通知を使用する場合
1. 「ツール」→「オプション」→「Eメール」でSMTP設定を行う
2. 送信元・送信先メールアドレスを設定
3. EAパラメータで「メール通知」をtrueに設定

## 使用方法

### 基本的な使い方
1. EAを任意のチャートにアタッチ
2. 必要に応じてパラメータを設定
3. 自動売買を有効にする

### スマホから緊急停止する方法
1. スマホのMT4/MT5アプリを開く
2. USDJPYで売り指値を200.0で発注、またはBTCUSDで売り指値を200000.0で発注
3. EAが検出し、自動売買がOFFになります
4. 該当注文を削除すると、自動売買が元の状態に戻ります

### 価格制限機能の使い方
1. 上限価格・下限価格を設定（0=無効）
2. 価格が制限を超えると自動的に全決済・停止

## 注意事項

- DLLの使用を許可する必要があります（自動売買ボタンの制御に使用）
- 価格制限機能でEAが停止した場合、再度チャートにアタッチし直す必要があります
- スマホ通知・メール通知を使用する場合は、事前にMetaTraderの設定が必要です
